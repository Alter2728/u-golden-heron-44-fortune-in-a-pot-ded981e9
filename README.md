One kind, funny fortune for a houseplant, written in the voice of a fortune slip:

> Your newest leaf will unfurl toward the morning sun, and your keeper will take full credit — let them. You knew first.

`main.py` (Python 3 stdlib only, deterministic) writes that single line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (fallback `/output/entry.txt`).

## Run it

```sh
python3 main.py
```
